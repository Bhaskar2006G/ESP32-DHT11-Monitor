ESP32 IoT Temperature and Humidity Monitor



Project Overview



This project uses an ESP32 microcontroller and a DHT11 sensor to measure temperature and humidity. The sensor readings are sent to ThingSpeak for online monitoring.



Components Used



\- ESP32 Development Board

\- DHT11 Temperature and Humidity Sensor

\- Connecting wires

\- Breadboard

\- USB cable



Software and Platforms



\- Arduino IDE

\- ThingSpeak IoT Platform



Circuit Connections



DHT11| ESP32

VCC| 3.3V

GND| GND

DATA| GPIO 4



Features



\- Measures temperature

\- Measures humidity

\- Sends sensor readings to ThingSpeak

\- Displays readings on an online dashboard



Testing



The ESP32 successfully sends temperature and humidity readings to ThingSpeak. The dashboard displays the sensor data.



How to Use



1\. Connect the DHT11 sensor to the ESP32.

2\. Open the Arduino code in Arduino IDE.

3\. Enter your Wi-Fi credentials and ThingSpeak API key.

4\. Upload the code to the ESP32.

5\. View the sensor readings on ThingSpeak.
